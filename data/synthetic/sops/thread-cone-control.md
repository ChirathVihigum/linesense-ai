# Thread Cone Control

> Synthetic demonstration document — not an official factory procedure.

## Purpose and Scope

This procedure covers issue and control of sewing thread — M07 Polyester Thread 40s, M08 Cotton Thread 50s, and M09 Overlock Thread — all measured and issued in cones, across every line at KTN and BYG. Thread is a high-consumption, low-unit-value item that is easy to over-issue informally, so this procedure exists separately from the general material issue procedure.

## Cone Issue

Cones are issued to a line's thread trolley in whole units only, sized to the planned run length for the style loaded on that line, and logged against the order the trolley is supplying. Operators do not draw thread directly from the store; all issue passes through the line's material handler so consumption stays traceable to an order.

## Empty Cone Return

Empty and part-used cones are returned to the trolley's return bin at the end of each shift rather than discarded, both to support a rough consumption check against the style's expected thread usage and to prevent part-used cones from being counted twice if picked up by the next shift.

## Colour and Lot Matching

Thread colour must match the style's approved shade card exactly; a visually close but unapproved shade is treated as a non-conformance and must be reported to the line supervisor before sewing continues, since a mismatched seam thread is a shade variation defect (DEF-SV) that inspection will otherwise catch far later in the process.

## Shortage Response

A thread trolley running low mid-shift raises a supermarket-style pull card to the store, following the Supermarket Replenishment procedure. Running a line without thread for even a single operation stops every downstream operation on that line, so thread pull cards are treated as the highest-priority replenishment class.

## Related Procedures and Review

Thread pull cards follow the same escalation path described in Supermarket Replenishment, and a persistent thread shortage on a specific line is reviewed jointly by the storekeeper and the line supervisor rather than resolved with a one-off large issue that bypasses normal trolley sizing. Thread consumption per style is periodically compared against the style's expected usage, derived from its seam length and stitch type, and a material sustained variance beyond a reasonable margin is investigated as a possible over-issue or miscount rather than accepted as normal variation.
