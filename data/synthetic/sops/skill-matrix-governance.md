# Skill Matrix Governance

> Synthetic demonstration document — not an official factory procedure.

## Purpose and Scope

This standard governs how operator skill levels are recorded and kept current as a process, so that line loading and changeover decisions can rely on an accurate skill matrix. It describes the process only; it does not itself list any individual operator's data.

## Skill Codes

Skills are recorded against the operation catalogue's skill codes: OL (overlock), SNLS (single-needle lockstitch), FL (flatlock/hemming), BH (buttonhole), BT (bartack/button attach), PRESS (pressing), and QC (final trim/quality check). Each operator alias holds a level from 1 to 4 for each skill code they have been assessed on.

## Assessment and Recording

Skill levels are assessed by the IE engineer against a documented checklist for each skill code and recorded under the operator's pseudonymous alias only, per the Worker Data Privacy procedure; no name or other personal attribute is ever recorded in the skill matrix.

## Matrix Review Cadence

The skill matrix for each line is reviewed at least monthly and immediately after any operator reassignment between lines, so that line loading decisions never rely on a skill record more than a few weeks stale.

## Use in Loading

Line loading checks a line's certified skills against a style's required operations before an order is assigned; a line missing a required skill at an adequate level is not loaded with that style until the gap is closed through training or reassignment, per the Line Loading Procedure.

## Related Procedures and Review

The skill matrix this standard governs is the authoritative input to Line Loading Procedure and Style Changeover, both of which check certified skills before assigning work to a line. Governance of the matrix is itself reviewed by the org_admin role annually to confirm that access remains restricted per Worker Data Privacy and that the assessment checklist for each skill code still reflects current machine and method standards across both the Katunayake and Biyagama plants. Any proposed change to a skill code's definition or assessment checklist is circulated to both plants' IE engineers before adoption, so a skill recorded at a given level means the same thing regardless of which plant assessed it.
